# 赛事工作台与打印资料

## 先选择赛事

管理员进入首页时先展示赛事中心。只有 URL 指定了可读取且未删除的赛事，才展示该赛事的现场调度入口；无效或已删除赛事返回赛事中心。切换赛事通过完整导航重新读取，棋盘编排、候场草稿和检录选择不跨赛事复用。读取空赛事不再隐式创建默认比赛。

## 创建四步

1. 基本信息：名称、学院、起止时间和地点，以及必填赛事密码、二次确认。比赛与密码同一事务创建。
2. 赛制与奖项：五子棋和军棋分别配置，通过项目切换查看。
3. 棋盘与裁判：按桌卡片添加裁判，只显示未分配和当前桌已选的裁判。可搜索姓名或邮箱，也可现场新建裁判账号。保留一人一桌、同桌多裁判约束；全部启用棋盘均有人负责才可继续。
4. 核对与创建：核对桌数及人数，配置自动备份，预览或下载明确标为草稿的裁判安排，确认后创建赛事。

新裁判账号的密码只在创建回包中出现，登录信息单独下载。选择器关闭前提醒保存，刷新或关闭浏览器也会提醒。账号创建是独立操作，取消创建赛事不会删除已经创建的裁判账号。

## 赛事内调度

- 现场运行：当前棋盘、叫号、开赛和暂停；敏感操作在点击提交后才弹出赛事密码与原因确认窗口。候场编辑草稿保留，发生他人修改时阻止覆盖。
- 棋盘与裁判：按桌编排，保存才成为正式安排。自动刷新的比分不覆盖未保存草稿；另一管理员修改棋盘绑定时阻止覆盖并提示加载最新安排。
- 检录与抽签：按项目搜索、分页，每页 12 人；可筛选未到场与优先，选中状态跨页保留。抽签和顺序变更继续要求赛事密码。
- 资料与打印：仅取已保存状态，未保存编排会提示。打印中心仅管理员可见。
- 赛事密码：独立配置进入赛事所需密码，与账号密码分开管理。

## 资料

| 资料 | 内容 | 用途 |
| --- | --- | --- |
| 裁判与棋盘安排 | 两项目桌号、该桌全部裁判、签到栏；默认 15 桌一张 A4 | 打印执裁安排、发群通知 |
| 现场对阵与候场 | 当前桌面状态、候场顺序、各轮完整对阵 | 现场协调、赛程归档 |
| 比赛成绩归档 | 导出时已确认对局、执裁署名、已有名次；未结束标记阶段性快照 | 阶段性或最终成绩留档 |

每份资料带赛事名称、时间地点、导出时间和状态版本。发群文字按当前快照生成，可复制或下载文本，由管理员发送。资料不含邮箱、密码和学号；成绩保留实际执裁姓名。待上场对局不预设桌号，以上场叫号为准；轮空、上游未定、待休息均不伪造比赛结果。

PDF 直接下载和浏览器打印独立提供，预览窗口可导出预览时那一版快照。长表自动分页，重复表头，过长的单行也分段续页。PDF 用于打印与查阅，机器恢复使用 JSON 自动或手动备份。既有的完整逐局比赛记录表 PDF 保留。

验证：42 项单元测试；浏览器覆盖创建四步、缺配阻止、多裁判同桌、已占用裁判过滤、新建账号及登录信息下载、未发布草稿 PDF、三类正式资料导出、打印、手机和黑白主题、角色可见性、自动备份、检录分页、赛事切换和无效赛事。PDF 样张通过 Poppler 渲染核对。

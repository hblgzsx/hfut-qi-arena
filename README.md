# 弈境 QI ARENA

合肥工业大学五院研究生棋类友谊赛现场系统，支持五子棋与军棋。

React + TypeScript + Vite；云端模式使用 Supabase Auth、Edge Functions、Postgres 和 Realtime。前端可部署到 GitHub Pages。

- 黑底竞技界面，校徽、棋盘、晋级流光、胜者播报与可选中文语音。
- 单项目或双项目一屏展示全部签位，自适应尺寸，展示页有退出与录分按钮。
- Excel 双工作表导入、随机抽签、轮空、BO1 / BO3、和棋续赛、弃权处理。
- 管理员点击大屏对局直接裁定胜方，修改原因必填；保留修改前后记录，受影响的后续成绩须确认重算。
- 成绩保存后先显示晋级路径 2 秒，再排队播报新赛果。
- 云端模式：管理员注册申请、超级管理员授权、管理员创建裁判随机密码、手机录分、并发冲突检测、公开数据脱敏。
- 奖品图片、成绩导出、完整 JSON 备份与恢复。

## 本地运行

需要 Node.js 22.18+：

```sh
npm install
npm run build
npm start
```

打开 http://127.0.0.1:4173/ 。开发模式 `npm run dev`。

未配置 `.env.local` 时是本地演示：数据只保存在各自浏览器，**不能用于跨设备实时录分**。云端配置完成后，未登录观众只读公开赛果，裁判由管理员创建后才能提交。

## 部署与验证

见 [云端部署说明](./云端部署说明.md) 和 [使用说明](./使用说明.md)。真实报名表、选手数据、备份及服务端密钥不要提交到仓库。

```sh
npm test
npm run test:arena
```

单元测试覆盖 2—256 人淘汰流程与云端权限、脱敏和并发合并策略。浏览器测试需要先启动系统，并安装本机 Edge。

正式网站：https://hblgzsx.github.io/hfut-qi-arena/ 。2026-11-16 已部署 Supabase 数据库、tournament 函数及 Realtime，并验证超级管理员登录、公开快照与私有数据访问隔离。正式比赛前仍应使用现场网络和手机进行多端试录分。

大屏“播报设置”可明确选择男声或女声，再选择设备提供的具体音色；可用时优先使用自然音色，以及标准、热烈、沉稳三种风格。完整播报项目、轮次（四分之一决赛、半决赛、决赛）、胜负和晋级去向；同一赛果版本只展示一次；默认最短 12 秒，可选 8 / 12 / 16 / 20 / 30 秒。语音较长时自动延长，并等待语音播完再切换。手动关闭可终止当前语音。

竞赛转播界面参考程序设计竞赛榜单的层次与信息密度，保留棋类淘汰逻辑。大屏默认全员竞赛总榜，可切换晋级树。赛事设置可载入每项目 32 / 64 / 128 / 256 人的双项目演示，最大文件预生成于 public/demo/max-256.json，全部为虚拟资料。

自动语音仅在现场大屏播放；同源浏览器多大屏使用 Web Locks 与已播标记保证同一赛果只读一次，控制台静音。不同设备分别启用语音时仍各有一套音响输出，现场只需在主大屏启用语音。
